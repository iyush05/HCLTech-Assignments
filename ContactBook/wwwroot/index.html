    HTTP Status Codes

    • 200 OK Standard response for successful GET, PUT, or PATCH.
    • 201 Created Returned by POST with a Location header.
    • 204 No Content Returned by DELETE when successfully removed.
    • 400 Bad Request Returned when model validation fails.
    • 404 Not Found Returned when the requested GUID does not exist.
